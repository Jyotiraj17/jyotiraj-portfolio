# Jyotiraj Panda — AI-Powered Full-Stack Portfolio Website

## 1. Project Overview

This project is a personal portfolio website for **Jyotiraj Panda**, designed as a modern, responsive, AI-powered full-stack web application.

The portfolio will present Jyotiraj's:

- Professional profile
- Education
- Internship experience
- Technical skills
- Projects
- Certifications
- Contact information
- GitHub and LinkedIn profiles
- AI-powered personal assistant

The website will use a simple frontend stack (**HTML, CSS, JavaScript**) with a backend built using **Node.js and Express.js**, and **MongoDB Atlas** as the database.

The portfolio will also include an **AI Assistant** capable of answering questions about Jyotiraj based on the information stored in the portfolio knowledge base.

# 16. Security

The backend should follow basic security practices.

### Environment variables

Sensitive configuration should be stored in `.env`.

Example:

```env
PORT=5000
MONGODB_URI=your_mongodb_atlas_connection_string
AI_API_KEY=your_ai_api_key
```

The `.env` file must not be uploaded to GitHub.

It should be included in `.gitignore`.
